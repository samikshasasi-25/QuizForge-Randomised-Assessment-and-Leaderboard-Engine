Features Implemented

- Topic-wise question selection.
- Randomised question selection using Python's "random" module.
- Multiple-choice questions.
- Positive and negative marking.
- Option to skip questions.
- Automatic score calculation.
- Answer review after quiz completion.
- Topic-wise leaderboard.
- Saving quiz results using JSON file handling.
- Displaying previously saved results.

Project Description

QuizForge is a Python-based randomised assessment system designed to conduct topic-wise quizzes. It selects questions randomly, evaluates user responses using a marking system, provides answer reviews, and maintains topic-wise leaderboards using JSON-based data storage.
